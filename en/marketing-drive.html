Hue Marketing Drive

A private connection for Hue's operator to maintain a working library of marketing images, videos, source versions, and publication evidence in a selected Google Drive folder. It is separate from the Hue iOS app.

Privacy notice

Effective: October 17, 2026

Access and purpose

The connection requests the Google Drive drive.file permission for files explicitly selected for the tool and files it creates for the operator. The marketing folder is selected during authorization. This permission does not authorize processing unrelated Drive files. The connection does not request Gmail access or access to the operator's entire Drive.

The selected media and file metadata, including names, file identifiers, sizes, source references, and integrity hashes, are used for version tracking, integrity checks, and approved media preparation and publishing tasks. The connection is not intended to back up app-user databases, source repositories, or arbitrary project files. Storing source footage does not authorize public publication of that footage.

Processing and sharing

Files are stored in the operator's Google Drive. Automated media processing is enabled only after the integration's data handling has been checked against the operator's authorization and Google's user-data requirements. Selected media may then be used with the approved automation or AI tools for the specific task. The storage connection does not provide model-training or fine-tuning features and does not sell data. OAuth credentials are kept in protected local storage and are not included in task prompts or public artifacts.

Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Retention and control

Files remain in the operator's Drive until the operator deletes them or requests cleanup. Local copies are retained as needed for the authorized work. The operator can request local cleanup; active work and unarchived deliverables must be checked before removal.

The operator can revoke the connection through Google Account permissions. Revocation stops further authorized access but does not automatically delete files in Drive, previously downloaded local copies, or locally stored credentials. Drive files can be managed directly in Drive. Local copies and credentials can be removed when retiring the connection. Refresh credentials are retained only to maintain the authorized connection.
